# Kapanigans

A co-op game for the Kapusta and Lanigan kids on iPad and iPhone. Up to 4 players color one picture together, each on their own part. When exactly 2 kids play, they get a video chat bubble.

- **Violet level (age 3):** big crayon, rainbow brush, tap-to-fill, stickers, Oops button
- **Quinn level (age 6):** marker, crayon, spray, glitter, fill, eraser, stamps, 3 sizes, 25 colors, undo

Play at https://joeker630.github.io/kapanigans/

Each device needs the same **family code** (set on first launch; tap the code chip in the lobby to change it). Live play, the Inbox and saved strokes run on Firebase Realtime Database (project `kapanigans`); video goes directly between the two devices.
